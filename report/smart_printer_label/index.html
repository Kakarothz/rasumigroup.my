Executive Summary

Print Automation & Reliability

VIMS Smart Printing Label is a Google Chrome extension that automates drug label printing directly from the VIMS pharmacy portal, running independently at each branch workstation.

Version 4 introduced 600 DPI Ultra HD printing, an auto size-lock that prevents accidental A4/Letter misprints, and Anti-Jamming server recovery that automatically refreshes the page when the VIMS portal throws its known `Persits.PdfManager` / `800a002e` error — previously a manual-intervention failure.

A Firebase-backed multi-branch SOC dashboard gives HQ live visibility into every branch's print activity, idle time, and error rate from one screen, with remote restart capability.
